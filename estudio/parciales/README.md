## Cómo usar un parcial

1. Intentá cada ejercicio sin mirar apuntes y anotá el tiempo.
2. Clasificá el caso antes de calcular: cinemática, DCL, roce, sistema, marco no inercial, MCU o dinámica radial.
3. Compará el planteo con la receta de la guía, no solamente con el resultado.
4. Registrá el error en [Errores frecuentes](../errores-comunes/README.md).
5. Repetí el ejercicio al día siguiente sin consultar la resolución.
