### Frecuencias observadas en esos siete PDF

Se cuenta presencia por examen, no cantidad de incisos. Las filas se superponen.

| Familia | Presencia | Lectura para la práctica |
| --- | --- | --- |
| Trabajo/Energía | 7/7 | Siempre hay una cadena de estados, no sólo sustituir una fórmula |
| Resorte dentro de una cadena energética | 6/7: S1–S6 | Convertir compresión, distinguir tramo con roce y estado de reposo |
| Momento lineal, choque o CM | 6/7: S1, S3–S7 | Elegir sistema e intervalo; usar componentes y signos |
| MAS o péndulo | 4/7: S1, S3, S4, S7 | Tres enlazan el resorte con una etapa anterior; uno usa péndulo |
| Energía y pista circular | 4/7: S1–S4 | Agregar Newton radial para contacto o normal; revisar el vínculo |
| Cadena explícita choque → resorte/MAS | 2/7: S1, S3 | Cambiar de principio y de masa oscilante en cada etapa |

**Patrón más útil:** pasar de un principio a otro sin mezclarlos:
energía para recorrido → momento para impacto → energía/MAS después.
No hay base para decir que un ejercicio «siempre» vuelve a tomarse.

## Advertencias comprobadas

- S2, S4 y otros rulos: «llegar arriba» no equivale a sostener contacto en
  una pista abierta por dentro. Si se exige contacto, usar N = 0 como límite;
  si hay sujeción bilateral, el criterio puede cambiar.
- S3: conservar el 90 % de **rapidez** conserva 0,9² = 81 % de K, no 90 %.
  «Aceleración radial y centrípeta» nombra la misma componente; no sumarlas dos veces.
- S4, ej. 2: para un alcance por detrás con v1i > v2i > 0, el dato
  v2f = 0,9v2i hace que por momento v1f = v1i + 0,2v2i. No representa
  una separación posterior de un choque pasivo ordinario. Comprobar el
  conjunto de datos antes de tratarlo como solución física válida.
- S6, ej. 3: el dibujo sugiere B inicialmente quieto, pero el texto no lo
  explicita. Declarar esa hipótesis al resolver.
- La hoja sin fecha dice «péndulo» en el ejercicio de **masa–resorte**:
  interpretar el dispositivo descrito, no cambiar a T = 2π√(L/g).
- Los datos personalizados de 2020–2021 se mantienen simbólicos. No hace
  falta usar ni compartir DNI o fecha de nacimiento: para practicar se pueden
  elegir datos ficticios, indicándolo.
