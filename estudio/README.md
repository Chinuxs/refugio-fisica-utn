# Material de estudio para Física I

Esta área reúne recursos para preparar parciales, recuperatorios y finales de
Física I. Está pensada para que cualquier compañero pueda encontrar y entender
el material sin tener que revisar el código del simulador.

## Organización

### Parciales y finales

Guardar en `parciales/` los enunciados originales, recuperatorios, finales y
simulacros. Cuando sea posible, registrar la fecha y el tipo de evaluación en
el nombre:

- `final-2025-02-15.pdf`
- `parcial-2-2025.pdf`
- `recuperatorio-parcial-1-2025.pdf`

Si un examen tiene una resolución propia, conviene guardarla en
`ejercicios/`, indicando claramente de qué examen y ejercicio proviene.

### Apuntes

Guardar en `apuntes/` la teoría explicada, resúmenes y formularios. Organizar
los documentos por tema, por ejemplo:

- `apuntes/dinamica/`
- `apuntes/movimiento-circular/`

### Ejercicios resueltos

Guardar en `ejercicios/` los problemas analizados y resueltos, clasificados por
tema. Usar nombres descriptivos y numerados:

- `dinamica-plano-inclinado-01.md`
- `movimiento-circular-vertical-01.md`

Los ejercicios no deben conservarse únicamente con el resultado. Cada
resolución debe incluir interpretación del enunciado, esquema o diagrama,
estrategia, desarrollo con unidades, verificación, errores típicos y el
aprendizaje principal. El formato completo está en
[`../AI_CONTEXT.md`](../AI_CONTEXT.md).

### Errores frecuentes

Usar `errores-comunes/` para registrar confusiones conceptuales y prácticas,
explicar por qué son errores y mostrar cómo detectarlos o corregirlos.

## Convenciones generales

- Escribir en español claro y usar Markdown simple para las resoluciones.
- No inventar datos ausentes; declarar toda hipótesis necesaria.
- Mantener el archivo original de cada examen sin modificar.
- Evitar duplicados: enlazar material existente cuando corresponda.
- Incluir siempre unidades y explicar el significado físico del resultado.
