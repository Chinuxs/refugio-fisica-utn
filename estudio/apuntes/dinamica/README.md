# Apuntes de Dinámica

Esta sección reúne conceptos, herramientas algebraicas y métodos de resolución
que aparecen al trabajar con ejercicios de Dinámica.

Los apuntes se construyen progresivamente a partir de parciales y ejercicios
reales. El objetivo no es memorizar fórmulas aisladas, sino entender por qué se
aplican y cómo reconocer cuándo conviene usarlas.

## Contenidos

- [Métodos de resolución](metodos-de-resolucion.md)
- Segunda Ley de Newton — pendiente.
- Diagramas de cuerpo libre — pendiente.
- Elección de ejes — pendiente.
- Tensión — pendiente.
- Rozamiento — pendiente.
- Marcos de referencia — pendiente.

## Forma de uso

Cada método debería incluir:

1. Situación en la que aparece.
2. Idea principal.
3. Justificación matemática.
4. Ejemplo aplicado a Física.
5. Error frecuente.
6. Regla práctica para el parcial.
