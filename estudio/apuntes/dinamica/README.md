## Criterio

Guardar cada conocimiento en la categoría que permita encontrarlo más rápido.
Para estudiar para un parcial, empezar por la [guía de casos](resolucion-por-casos.md)
y saltar desde allí a la resolución completa. Los apuntes se construyen
progresivamente a partir de ejercicios reales.
